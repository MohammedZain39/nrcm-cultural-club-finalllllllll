# NRCM Cultural Club Website

A responsive, single-page brochure website for the Narsimh(a) Reddy Engineering College Cultural Club.

## Included
- Responsive landing page
- Smooth scroll + reveal animations
- Cultural Club introduction
- Faculty/student leadership cards
- Team photo section
- Freshers Event section
- Central-college-event highlight
- Creators' Club backend/support note
- Instagram DM links
- Final "Scan to Join Us" QR section
- Native share button on supported mobile browsers

## Run locally
Open `index.html` in a browser.

For the cleanest local preview, use a small static server such as VS Code Live Server.

## Deploy
This is a static site, so it can be deployed directly to GitHub Pages, Netlify, Vercel, or any normal web host.

## Important
The Freshers Event QR is preserved from the supplied artwork. Before publishing, test the QR with a phone camera. If the registration destination changes, replace `assets/join-qr.jpg` with the new QR artwork.
